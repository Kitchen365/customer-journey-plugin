# Question bank

Ready picker questions. Ask only those the request and the account have not
already answered, up to 4 in one picker. Fill options marked `<...>` from the
account. The first option is the default; mark it "(Recommended)" when it is.

## Purpose (ask first, it decides the rest)

**Who will use this dashboard?**
- A manager overseeing the team (Recommended)
- Each salesperson, for their own numbers
- Leadership, a monthly summary
- Me, a one-off analysis

**What should it help decide?**  (multi-select)
- Who needs coaching, and on what
- Where leads and deals are being lost
- Whether we respond to leads fast enough
- How the pipeline is trending

## Scope

**Which areas should it cover?**  (multi-select; list only granted areas that
have data)
- Calls and call quality
- Leads and speed to lead
- Deals and pipeline
- Meetings / Messages and chats / Support tickets / AI cost

**Who is the team?**
- All active agents except shared inboxes (Recommended)
- `<a group read from find_agents, e.g. people who own deals>`
- Let me pick people on the dashboard
- Everyone, including inactive

**Leave these shared inboxes out?**  (multi-select; only names that look like
inboxes: "Customer Service", "Design Team", "<Company> Marketing"...)
- `<inbox 1>` / `<inbox 2>` / `<inbox 3>` ...

## Defaults

**Default period?**
- Last 30 days (Recommended)
- This month
- This quarter
- Last 7 days

**Win rate over which deals?**  (only when deals are in scope)
- Deals closed in the period: what was decided (Recommended)
- Deals created in the period: what new deals became

**Connect rate over which calls?**  (only when the account has many
`no_recording` calls)
- All calls (Recommended)
- Only calls with a recording

## Shape

**How should it be laid out?**
- Tabs: overview, then one per area (Recommended)
- One long page
- Team view and per-person view

**Anything to add?**  (multi-select)
- A leaderboard comparing people
- Example records behind each number (worst calls, lost deals)
- An AI-written coaching page per person
- Export (CSV / file)

## Confirming and closing

**Plan ready. Build it?**
- Build this (Recommended)
- Change something
- Fewer tabs, keep it simple

**How does it look?**  (multi-select, after handing over)
- Numbers look right
- Something's missing
- Something's not needed
- A number looks wrong

A "Change something", "missing" or "wrong" answer gets one short follow-up
picker or, when the answer is genuinely open, one line asking what. Then fix it.
